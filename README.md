# MK Шаблони

Платформа брендових шаблонів MK Consulting. Будь-хто в компанії обирає шаблон, заповнює поля (або просить AI написати текст) і завантажує результат у PNG, PDF чи PPTX.

## Шаблони
| Шаблон | Розмір | Експорт |
|---|---|---|
| Презентація | 1280×720 | PNG, PDF, **PPTX з текстом, що редагується** |
| Пост для соцмереж | 1080×1080 | PNG, PDF, PPTX |
| Вакансія | 1080×1080 | PNG, PDF, PPTX |
| Флаєр A5 | 148×210 мм, 300 dpi | PDF для друку, PNG |
| Візитівка | 90×50 мм, 2 сторони | PDF для друку, PNG |

Бренд (кольори, лого, правила) береться зі скілу `mk-brand-design`, див. `lib/brand.ts`.

## Шрифт e-Ukraine
Файли шрифту лежать у `public/fonts/` (Light, Regular, Medium, Bold, формат otf).
Шрифт e-Ukraine розповсюджує Мінцифри (plan.diia.gov.ua). Якщо якогось файлу немає, сайт підставляє Inter.
Щоб презентація у PPTX відкривалася з правильним шрифтом, e-Ukraine має бути встановлений на комп'ютері.

## AI-помічник
Потрібна змінна середовища `ANTHROPIC_API_KEY` (Vercel → Project → Settings → Environment Variables).
Без неї все працює, крім кнопки «Заповнити з AI».

## Як додати новий шаблон
1. Опишіть його в `lib/templates.tsx`: розмір, поля, приклад даних, функцію `render`.
2. Додайте в масив `TEMPLATES`. Каталог і редактор підхоплять його автоматично.

## Локальний запуск
```bash
npm install
npm run dev
```
